# React Redux TypeScript Learning

Ein bewusst kleines Lernprojekt für Redux Toolkit mit React und TypeScript.

## Installation

```bash
npm install
npm run dev
```

Danach `START_HERE.md` öffnen.

## Ausgangszustand

Die Todo-App verwendet zunächst `useState`. Redux Toolkit und React Redux sind bereits als Dependencies installiert, aber noch nicht in der App eingerichtet.

So kann die App Ticket für Ticket von lokalem React-State zu Redux migriert werden.
